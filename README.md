# Project Student Grades Management System

This project contains the code for
a Java management system for
student grading which is able to:

* Store grades for a class of students.
* Allow the user to input grades.
* Calculate the average grade.
* Find the highest and lowest grades.
* Display all grades.

The program has been built inside a class
named `StudentGrades` and follows the steps below:

## 1. Declare and Initialize Arrays
* Declare an array `grades` to store the grades of `10` students.
* Initialize a `Scanner` object to allow the user to input grades.

## 2. Implement Array Operations
* Prompt the user for grades using the `Scanner` object and store them in the array.
* Calculate and print the average grade.
* Find and print the highest and lowest grades.
* Display all the grades.
